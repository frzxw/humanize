# Security

This repository is a markdown skill. It has no server, no package dependencies, and no secrets.

If a pattern or example would make an agent leak private data, run a destructive command, or hide an instruction from the person using it, email the report to [frzwibisono@gmail.com](mailto:frzwibisono@gmail.com).

Include the file and the lines, what the agent did, and which agent you used. Do not open a public issue for this.
